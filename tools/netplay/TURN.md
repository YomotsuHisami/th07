# TH07 WebRTC TURN deployment

The production fallback target is coturn using TURN REST-style temporary
credentials. Keep the shared secret server-side; browsers receive only the
short-lived username/HMAC credential from `lan-relay.cjs` signaling.

## Minimal setup

1. Install coturn on the VPS.
2. Copy `coturn.env.example` to a server-only environment file and replace the
   realm/secret/hostname values. Keep that file out of the repository. A simple
   secret source is `openssl rand -hex 32`; the renderer deliberately rejects
   secrets shorter than 24 bytes, so the checked-in `CHANGE_ME` cannot start.
3. Use the same `TH07_TURN_SHARED_SECRET` for `lan-relay.cjs` and coturn.
4. Render coturn configuration:

   `node render-coturn-config.cjs --output /etc/turnserver.conf`

5. Open TCP+UDP 3478 and UDP `TH07_TURN_MIN_PORT..TH07_TURN_MAX_PORT` in the
   host/cloud firewall. If TURN/TLS is enabled, also open its configured TCP
   port (default 5349).
6. Restart coturn and the signaling service, then verify browser diagnostics
   report `__eaglerNetplayTransport === "rtc"`; a true TURN path reports
   `__eaglerNetplayPath === "turn"`.

## Deliberately simple security baseline

- `use-auth-secret` + a server-only shared secret.
- Short-lived credentials generated by signaling; default TTL is 3600 s.
- No anonymous TURN configuration.
- coturn CLI disabled and multicast peers denied.
- Common private/reserved IPv4 destinations denied so TURN is not an internal
  network proxy.
- Per-user/total allocation quotas and per-session/server bandwidth caps.
- No project-specific room JWT or TURN credential binding. Add such a layer
  only if real abuse data justifies it.

The default `bps-capacity=786432` is intentionally conservative for the current
roughly 10 Mbps VPS and leaves bandwidth headroom for the website/signaling.
Measure real TH07 traffic during beta before raising it.

TURN/TLS is optional. Without `TH07_TURN_CERT` and `TH07_TURN_PKEY`, the
generated config keeps TURN/UDP and TURN/TCP on port 3478 and disables TLS.
